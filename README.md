# AI8051U 智能车蓝牙控制台

这是为 AI8051U 智能车和 JDY-31 蓝牙模块制作的移动端网页控制器。页面默认使用 Web Serial 连接已经配对的 JDY-31 SPP 串口蓝牙，同时保留 FFE0 / FFE1 BLE 备用连接，可控制循迹、倒车、停车和速度档位，并实时显示发车计时、四路电感传感器、循迹误差及十字路口状态。发送 `F` 后计时器自动清零开始，发送 `S` 后停止，下一次发车重新计时。

## 已适配的固件协议

### 网页发送

| 功能 | ASCII 命令 |
| --- | --- |
| 开始 PD 循迹 | `F` |
| 倒车 | `B` |
| 停车 | `S` |
| 55%～95%速度（每档5%） | `1`～`9` |
| 100%满速 | `0` |

### 单片机返回

网页解析以下格式：

```text
L1=250 L2=265 R1=288 R2=450 SUM=1253 ERROR=0 CROSS=0
```

也会识别：

```text
CAR ALIVE
PID FORWARD
BACKWARD
STOP
SPEED=60
```

## 参数调整模块

网页把“车辆控制”和“参数调整”分为两个独立模块。进入参数调整模式时，单片机会先停车并锁定普通驾驶命令；退出后车辆仍保持停车，需要重新发送 `F` 或 `B` 才会运动。

调参协议使用 `@` 开头并以换行结束，不会与原来的单字符驾驶协议冲突：

| 功能 | 命令示例 |
| --- | --- |
| 进入/退出调参模式 | `@MODE 1` / `@MODE 0` |
| 读取全部参数 | `@GET` |
| 修改参数 | `@SET KP_DIV 95` |
| 恢复代码默认值 | `@DEFAULT` |

运行时可调整 PID、四路传感器基准、十字路口识别、速度上限和数据返回周期。PWM 频率涉及硬件定时器重装值，目前仅显示，修改后需要重新编译和烧录固件。

D 项使用固定控制周期差分与整数低通滤波；`D_FILTER=1` 表示不滤波，数值越大越平滑，默认值为 `4`。当前固件代码默认参数为 `KP_DIV=95`、`KD_DIV=25`，四路基准为 `L1_BASE=93`、`L2_BASE=90`、`R1_BASE=200`、`R2_BASE=150`；网页进入调参模式后仍以单片机实际回读值为准。十字路口继续使用独立的 P 分母，不再改变速度档位。

十字路口会先将四路ADC分别减去对应BASE并钳位到0，再计算左右峰值和左右有效能量。条件A要求：左右校正峰值都超过 `CROSS_SIDE_MIN=150`，左右有效能量都超过 `CROSS_ENERGY_MIN=250`，并且弱侧峰值至少达到强侧峰值的 `CROSS_BALANCE=50%`。四路原始值全部超过 `CROSS_ALL_MIN=1200` 时仍可独立确认。四路 `SUM` 继续返回用于观察和画图，但不再独立触发十字路口。

网页参数只在当前上电期间有效；单片机重新上电后会恢复 `Sources/inc/tuning_params.h` 中的默认值。

为避免周期性传感器上传影响调参命令应答，进入调参模式后固件会暂停传感器上传。网页逐条发送参数并等待 `OK PARAM` 确认，回复超时会自动重试一次；全部修改完成后再回读所有参数进行校验。退出调参模式后恢复传感器数据上传。

## 传感器波形调试

“传感器调试”模块直接使用现有遥测数据绘制两张固定量程波形图：第一张同时显示 L1、L2、R1、R2（0～4000），第二张显示左侧 `L1+L2` 与右侧 `R1+R2`（0～7000）。两张图都会根据 `CROSS` 状态变化画出竖向虚线：绿色表示进入十字路口，红色表示退出十字路口。支持选择显示点数、暂停/继续、清空以及导出当前记录为 CSV；CSV 同时包含 `CROSS` 与 `cross_event`，这些操作只影响网页记录，不会改变单片机运行状态。

## 蓝牙参数

- 模块：JDY-31
- SPP 服务 UUID：`00001101-0000-1000-8000-00805F9B34FB`
- BLE 服务：`0000FFE0-0000-1000-8000-00805F9B34FB`
- 收发特征：`0000FFE1-0000-1000-8000-00805F9B34FB`
- 单片机串口：57600 baud、8N1

SPP 模式会调用系统已配对设备列表，并按标准串口服务筛选。首次授权后，浏览器支持 `getPorts()` 时可以通过“上次设备”重连。网页不能自行完成静默配对，也不能按 MAC 地址自动选择设备。

BLE 模式按可编辑的设备名称前缀筛选，并通过浏览器匿名设备 ID 记住上次授权模块。

## 本地运行

Web Serial 和 Web Bluetooth 都要求安全来源。`localhost` 可以直接使用：

```powershell
python -m http.server 8000
```

然后使用 Chrome 或 Edge 打开：

```text
http://localhost:8000
```

不要直接双击 `index.html` 测试蓝牙。

## 手机使用

- Android：SPP 模式需要支持蓝牙串口 Web Serial 的新版 Chrome。
- 使用 SPP 前，先在手机系统蓝牙设置中配对 JDY-31，再从网页点“连接 SPP”。
- iPhone/iPad：浏览器无法使用经典蓝牙 SPP；只能使用模块的 BLE 模式或原生应用。
- 模块一次只能连接一个客户端，使用网页前请先断开蓝牙串口助手。

## 文件

- `index.html`：页面结构
- `styles.css`：移动端响应式样式
- `app.js`：Web Serial / Web Bluetooth、命令发送和数据解析
- `tuning.css`：参数调整模块样式
- `tuning.js`：参数模式、读取、校验和应用逻辑
- `sensor-charts.css`：传感器波形与移动端样式
- `sensor-charts.js`：波形绘制、暂停、清空和 CSV 导出

## 安全提示

首次测试时请架空车轮，确认 `F`、`B`、`S` 方向和停车功能正确后再把车放到地面。0档是100%占空比，测试时注意电机驱动和电池温度。
