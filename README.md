# AI8051U 智能车蓝牙控制台

这是为 AI8051U 智能车和 JDY-31 蓝牙模块制作的移动端网页控制器。页面使用 Web Bluetooth 连接 JDY-31，可控制循迹、倒车、停车和速度档位，并实时显示四路电感传感器、总和、循迹误差及十字路口状态。

## 已适配的固件协议

### 网页发送

| 功能 | ASCII 命令 |
| --- | --- |
| 开始 PD 循迹 | `F` |
| 倒车 | `B` |
| 停车 | `S` |
| 10%～90%速度 | `1`～`9` |
| 100%满速 | `0` |

### 单片机返回

网页解析以下格式：

```text
L1=250 L2=265 R1=288 R2=450 SUM=1253 ERROR=0 CROSS=0
```

也会识别：

```text
CAR ALIVE
PID FORWARD
BACKWARD
STOP
SPEED=60
```

## 蓝牙参数

- 模块：JDY-31
- 目标广播名称：`JDY-31-SPP`（网页会严格过滤并再次校验）
- BLE 服务：`0000FFE0-0000-1000-8000-00805F9B34FB`
- 收发特征：`0000FFE1-0000-1000-8000-00805F9B34FB`
- 单片机串口：9600 baud、8N1

Web Bluetooth 出于隐私保护不允许网页读取或指定设备 MAC 地址，因此不能直接使用类似 `22:0C:18:0B:1F:DC` 的地址连接。网页首次按名称选择成功后，会保存浏览器提供的匿名设备 ID；浏览器支持 `getDevices()` 时，后续点击连接会优先重连这个已授权设备。某些第三方浏览器不支持该接口时，仍会显示经过名称过滤的设备选择窗口。

## 本地运行

Web Bluetooth 要求安全来源。`localhost` 可以直接使用：

```powershell
python -m http.server 8000
```

然后使用 Chrome 或 Edge 打开：

```text
http://localhost:8000
```

不要直接双击 `index.html` 测试蓝牙。

## 手机使用

- Android：推荐最新版 Chrome。
- iPhone/iPad：Safari 不直接支持 Web Bluetooth，可使用 Bluefy 打开 HTTPS 页面。
- JDY-31 不要提前在系统蓝牙设置中配对，应点击网页中的“选择 JDY-31”。
- 模块一次只能连接一个客户端，使用网页前请先断开蓝牙串口助手。

## 文件

- `styles.css`：移动端响应式样式

## 安全提示

首次测试时请架空车轮，确认 `F`、`B`、`S` 方向和停车功能正确后再把车放到地面。0档是100%占空比，测试时注意电机驱动和电池温度。
